# رفيق — Rafiq

تطبيق مرافق لنموذج بارينة التربوي: رفيق المعلم، رفيق المدير، رفيق الوكيل (الأم المرجع)، رفيق المجموعة (المضيفة).

- يعمل على أندرويد وآيفون، ويعمل بدون إنترنت بعد أول فتح.
- يتبادل الفاعلون المعلومات عبر رسائل واتساب (نسخ الرسالة ثم لصقها في التطبيق).
- نسخة تجريبية للنقاش والتحسين.

## Installer Rafiq sur un téléphone

**Android (Chrome)** : ouvrir le lien de l'application → menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».

**iPhone (Safari, iOS 15 ou plus)** : ouvrir le lien dans Safari → bouton Partager □↑ → « Sur l'écran d'accueil ».

Toujours ouvrir Rafiq depuis son icône : les données sont gardées dans l'application installée.
